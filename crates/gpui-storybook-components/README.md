# gpui-storybook-components

[![Codecov: gpui-storybook-components][codecov-badge]][codecov]
[![crates.io: gpui-storybook-components][crate-badge]][crate]

`gpui-storybook-components` contains the shared sidebar and drag primitives used
by `gpui-storybook-core`. It is a runtime implementation crate; application
developers should use the [`gpui-storybook` facade][facade].
